# InsureShield API Reference Manual

Base URL: `http://localhost:5000/api`

---

## 1. Authentication Endpoints

### `POST /api/auth/register`
Registers a new advisor agent account.

**Request Body:**
```json
{
  "name": "David Miller",
  "email": "agent@test.com",
  "mobile": "+1 (555) 234-5678",
  "password": "Password123!"
}
```

**Response (201 Created):**
```json
{
  "success": true,
  "message": "Agent registered successfully",
  "data": {
    "agent": {
      "_id": "6aab8047e06efa41b14bf738",
      "name": "David Miller",
      "email": "agent@test.com",
      "mobile": "+1 (555) 234-5678",
      "role": "agent"
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

---

### `POST /api/auth/login`
Authenticates agent and returns JWT Bearer token.

**Request Body:**
```json
{
  "email": "agent@test.com",
  "password": "Password123!"
}
```

---

### `GET /api/auth/me`
Retrieves currently authenticated agent profile.
*Requires `Authorization: Bearer <token>`*

---

## 2. Customer Endpoints

### `GET /api/customers`
Lists all customers created by the authenticated agent with pagination and search.

**Query Parameters:**
- `search`: Filter by name, email, phone, city
- `page`: Page number (default: 1)
- `limit`: Items per page (default: 50)

---

### `POST /api/customers`
Creates a new customer underwriting profile.

**Request Body:**
```json
{
  "firstName": "Marcus",
  "lastName": "Sterling",
  "email": "marcus.sterling@example.com",
  "mobile": "+1 (555) 890-1234",
  "age": 36,
  "gender": "male",
  "occupation": "Fintech Director",
  "annualIncome": 165000,
  "city": "New York",
  "state": "NY",
  "vehicleType": "car"
}
```

---

### `GET /api/customers/:id`
Retrieves customer details by ID.

---

## 3. Product & Eligibility Endpoints

### `GET /api/products`
Lists insurance products.
*Query Parameter: `categoryId` (optional filter)*

---

### `GET /api/products/categories`
Lists all 5 insurance categories.

---

### `GET /api/products/eligible/:customerId`
Evaluates the customer's eligibility in real-time against all products.

**Response Structure:**
```json
{
  "success": true,
  "data": {
    "customer": { ... },
    "eligibleProducts": [ ... ],
    "ineligibleProducts": [
      {
        "product": { ... },
        "reasons": ["Product requires applicant age to be between 18 and 60."]
      }
    ],
    "totalEligible": 9
  }
}
```

---

## 4. Quotation Endpoints

### `POST /api/quotes/generate`
Generates personalized quotation PDF, uploads to Cloudinary/storage, and saves Quote record.

**Request Body:**
```json
{
  "customerId": "6aab8047e06efa41b14bf739",
  "productId": "6aab8047e06efa41b14bf73a",
  "notes": "Optional advisor notes"
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "quote": {
      "_id": "6aab8047e06efa41b14bf750",
      "generatedPdfUrl": "http://localhost:5000/uploads/quotes/quote_17896.pdf",
      "premium": 550,
      "coverageAmount": 1000000,
      "status": "generated"
    },
    "whatsAppShareUrl": "https://wa.me/15558901234?text=Hello%20Marcus..."
  }
}
```

---

### `GET /api/quotes`
Lists quotations generated by the agent.

---

## 5. Payments & Activation Endpoints

### `POST /api/payments/create-link`
Initializes a Stripe Checkout session and generates WhatsApp payment share link.

**Request Body:**
```json
{
  "quoteId": "6aab8047e06efa41b14bf750",
  "customerId": "6aab8047e06efa41b14bf739"
}
```

---

### `POST /api/payments/simulate-success/:id`
Testing endpoint to simulate payment completion, activate policy, and trigger Resend email.

---

### `POST /api/payments/webhook`
Stripe Webhook handler receiving `checkout.session.completed` events.
